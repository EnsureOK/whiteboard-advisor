macOS 安装

  1. 双击下载的 .dmg，把「经纪人智能体工作台」拖进「应用程序」文件夹。
  2. 在访达侧栏弹出（推出）DMG 磁盘，之后从启动台打开应用。
  3. 首次打开如提示「无法验证开发者」：右键应用 → 打开；若仍被拦，去 系统设置 → 隐私与安全性，页面底部点「仍要打开」。这只需要做一次。
不确定自己是什么芯片？点左上角 → 关于本机：「芯片 Apple M…」选 Apple 芯片版，「处理器 Intel…」选 Intel 版。

Windows 安装

  1. 右键下载的 .zip → 全部解压缩，解压到任意位置（如 D:\工作台）。
  2. 打开解压后的文件夹，双击 workbench.exe 启动。
  3. 如出现蓝色「Windows 已保护你的电脑」：点 「更多信息」→「仍要运行」。这只需要做一次。
  4. 建议右键 workbench.exe → 发送到桌面快捷方式，方便日常打开。
2015 年后的电脑一般都是 64 位；32 位包仅给极老设备兜底，功能相同。

Linux 安装

  1. 解压：tar xzf workbench-linux-x64.tar.gz
  2. 运行：./workbench（需要 GTK / WebKit2GTK 运行库）
